# Platforms

This page tracks which emulators and Linux handheld platforms `RAOfflineProxy` currently supports or has plans to support.

## Android

- RetroArch
- Dolphin
- PPSSPP
- ARMSX2
- Flycast (planned, [pending release](https://github.com/flyinghead/flycast/pull/2371))
- MelonDS ([planned](https://github.com/misantronic/RAOfflineProxy/issues/1), [PR created](https://github.com/rafaelvcaetano/melonDS-android/pull/1633))

## [Linux](/linux-support/)

- KNULLI (RetroArch)
- Onion (RetroArch)
- muOS (RetroArch)
- ROCKNIX (planned)
