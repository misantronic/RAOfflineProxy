# Platforms

This page tracks which emulators and Linux handheld platforms `RAOfflineProxy` currently supports or has plans to support.

## Android

- RetroArch
- Dolphin
- PPSSPP
- ARMSX2
- MelonDS ([planned](https://github.com/misantronic/RAOfflineProxy/issues/1), [PR created](https://github.com/rafaelvcaetano/melonDS-android/pull/1627))

## [Linux](/linux-support/)

- KNULLI
- Onion
- ROCKNIX (planned)
